# 25時、ナイトコードで — 次の25時まで。

参照《剧场版 世界计划 崩坏的世界与无法歌唱的初音未来》剧中画面制作的静态网页

## 「25点」的计算规则

使用访问者设备的本地日期和时区。
到点显示 `00:00:00` 一秒，然后进入下一轮。  
页面每次根据真实时间戳重新计算，切换标签页或电脑休眠后会重新同步。  
夏令时切换时按浏览器的日期规则处理。
